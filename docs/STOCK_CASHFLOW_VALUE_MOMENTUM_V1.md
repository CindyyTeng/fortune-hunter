# 現金流價值動能策略 v1

- 驗證區間：2020-01-01 至 2025-12-31，共三段各 24 個月的樣本外驗證。
- 資料：官方 OHLCV、官方月度股價淨值比、MOPS 季度營業現金流；所有財報僅在 effectiveDate 後使用。
- 方法：每段只在 72 個月訓練期選擇策略與參數，驗證期固定不調整。
- 結果：月均 0.371%、年化 4.1918%、最大回撤 -14.11%、243 筆、PF 1.3043。
- 基準：0050 月均 1.6981%；公平隨機 0.3165%。
- 限制：現金流殖利率的市值分母由股價淨值比乘最新權益估算，應視為研究近似值。
- 結論：找不到通過驗證的現金流價值動能策略，不可紙上交易或實盤。

# 重大訊息資料管線

## 結論

證交所政府開放資料提供上市與上櫃公司每日重大訊息 CSV，欄位含發言日期、時間、主旨及說明，適合排程每日累積。這兩個檔案是每日快照，未確認可直接指定歷史日期。

MOPS `t05st01` 可依「公司＋年度」查詢舊資料；實測上市 2330 與上櫃 6488 的民國 110、113 年皆有結果。不過全市場多年回填需要大量請求，目前不自動執行，避免對官方服務造成負擔。歷史研究先走人工 CSV 匯入。

## 時間點規則

每筆資料保留官方發言日期與時間。策略禁止公告當日使用，`effectiveDate` 先設下一個平日，回測再取不早於該日的第一個真實交易日。原始同日快照不覆寫，以免未來修訂造成資料洩漏。

## 指令

* `npm run data:probe-material-information`：檢查官方每日檔與公司年度歷史查詢。
* `npm run data:fetch-material-information`：下載並標準化當日上市、上櫃資料。
* `npm run data:backfill-material-information`：受控回填成交值前 60 檔普通股 2021–2025 年歷史主旨；有倖存者偏差，只供事件初篩。
* `npm run data:import-material-information`：匯入人工下載的歷史 CSV。
* `npm run data:validate-material-information`：檢查欄位與時間點安全性。

## 本輪結果

受控回填取得 60 檔高流動性普通股、2021–2025 共 18,175 筆歷史重大訊息，300 個公司年度請求零失敗。這不是歷史全市場股票池，存在倖存者偏差。

事件初篩後，只有現金增資事件 20 日報酬在訓練與驗證同時通過基本統計門檻；但完整投組驗證僅 88 筆、月均 0.1917%、年化 2.1844%、PF 1.1937、最大回撤 -5.63%，明顯輸給同期 0050 年化 38.591%。因此沒有可進 paper trading 或實盤的策略。

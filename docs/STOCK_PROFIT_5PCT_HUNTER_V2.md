## 風險警告

此版本靠低波動期提高曝險達標，驗證回撤低於 -20%，但訓練期回撤低於 -20%，仍需更嚴格資金與下單單位審核。

## 重要限制

這版沒有使用 ETF/0050 作為主策略，也沒有使用出場後才知道的欄位。最佳研究版已跨過月均 5%，但靠較高曝險達成，訓練期回撤較深；可實盤風控邊界版能把訓練與驗證回撤都壓在 -20% 內，但月均降到約 4.5367%。下一步若要同時「可實盤」與「月均 5%」，需要新增更強的進場 alpha 或更細的出場/熔斷規則，而不是單純加槓桿。

## 月內熔斷測試

已測試每月累計虧損達 -6%、-8%、-10%、-12% 後停止該月後續交易。結果沒有找到同時滿足訓練/驗證回撤皆不低於 -20%、驗證月均達 5%、交易與月份覆蓋足夠的組合。此路徑暫不重複測試，下一步應改進原始進場 alpha 或出場規則。

## 個股白名單測試

已測試用訓練期每檔交易數、平均交易報酬與 Profit Factor 產生個股白名單，再套用到驗證期。結果沒有找到同時滿足訓練/驗證回撤皆不低於 -20%、驗證交易數足夠且月均達 5% 的組合。此路徑暫不重複測試。

## 正式出場規則搜尋

已執行 npm run optimize:exits10y，使用 forwardPrices 重新計算持有天數、停損、移動停利與出場模式。最佳輸出測試期月均約 2.57%，最大回撤 -44.02%，未優於目前可實盤風控邊界，因此暫不採用。

## Alpha 候選池搜尋

已執行 alpha-ranking-only 與 selected-alpha-only 候選池搜尋。兩者最佳輸出測試期月均約 2.57%，最大回撤 -44.02%，交易 514，未優於目前可實盤風控邊界，因此暫不採用。

## 剩餘候選池與市場分層模式

已批次測試 alpha-risk-frontier、alpha-breadth、breadth-risk、market-band 四種模式。四者最佳輸出皆約為測試期月均 2.57%、最大回撤 -44.02%、交易 514，未優於目前可實盤風控邊界，因此暫不採用。

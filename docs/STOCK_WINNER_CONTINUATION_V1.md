# 純個股強勢延續策略 v1

## 結論

本版只交易台股普通股，不以 ETF 或 0050 為主要標的。它是目前研究中較佳的純個股版本，但驗證月均 `3.6232%`，仍未達 `5%`，因此只能列為研究候選，不能宣稱可實盤。

## 回測結果

| 項目 | 完整區間 | 後段驗證 |
| --- | ---: | ---: |
| 區間 | 2016-06～2026-06 | 2022-01～2026-06 |
| 月數 | 119 | 53 |
| 月均總資產報酬 | 2.1546% | 3.6232% |
| 最大回撤 | -19.83% | -19.83% |
| 交易數 | 395 | 184 |
| 勝率 | 50.38% | 58.15% |
| Profit Factor | 2.389 | 2.713 |

已計入買賣手續費、賣出交易稅、雙邊滑價與 T+2。回測結果不等於未來保證獲利。

## 選股與交易

1. 只接受普通股，排除 ETF 與 `0050`。
2. 大盤 20 日動能至少 3%，只在多方環境開新倉。
3. 個股評分至少 65、接近一年高點、20 日均成交值至少 3,000 萬元，並排除爆量出貨。
4. 候選股依推薦分數、RSI、量比及波動品質排序。
5. 一般單檔 22%，單檔上限 30%，單筆帳戶風險上限 2.5%，最多 12 檔。
6. 最多持有 10 個交易日；收盤跌破 10% 停損；黑天鵝條件成立時停止新倉。
7. 當月已實現報酬達 2% 後才放大 1.5 倍；達 20% 後停止新倉，避免持續追價。

## 驗收限制

- 與原本約 3.30% 的版本相比，月均提高，回撤仍低於 20%，但交易數沒有同步增加。
- 訓練月均約 0.98%，後段驗證約 3.62%，落差偏大；而且同一驗證區間已被反覆用於研究，不能再視為完全未碰觸的樣本外資料。
- 歷史股票池可能存在倖存者偏差。
- 在新增未碰觸資料或累積足夠紙上交易之前，不得接真實券商 API 下單。

重現指令：`node scripts/optimize-realized-10y.mjs --stock-objective=profit5 --monthly-pyramid-only`

研究方向參考：[台灣市場 52 週高點與動能研究](https://www.sciencedirect.com/science/article/pii/S1059056015001859)、[台灣市場動能持續性研究](https://www.sciencedirect.com/science/article/pii/S0927538X23000094)。研究亦指出台股動能報酬具市場狀態與季節差異，不能假設固定月均 5%。

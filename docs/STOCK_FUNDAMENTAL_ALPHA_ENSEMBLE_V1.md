# 純個股基本面事件 Alpha 組合 v1

## 結論

本版只交易台股個股，ETF 與 0050 的實際交易占比為 0%；0050 僅作績效比較。標準化意外營收與標準化意外盈餘共用同一帳戶、現金、T+2、曝險與風控後，沒有形成更高報酬的可實盤組合。

共用投組月均報酬距離 5% 目標仍差 4.7161 個百分點，且低於 0050 同期月均 2.2346%。公平隨機組合月均 0.0371%、最大回撤 -19.3359%，因此事件訊號仍優於隨機，但不具備足夠報酬。

## 驗證方式

- 每個來源皆使用 54 個月訓練、18 個月固定驗證，組合只接收各折樣本外訊號。
- 單一帳戶最多持有 20 檔，單檔上限 6%，單筆帳戶風險 0.4%。
- 使用共用成交模擬器處理手續費、交易稅、滑價、跳空不利成交與 T+2。
- 同日同股只保留一筆訊號，避免兩個來源重複買進。
- 回撤熔斷改為首次跨越門檻才觸發；冷卻期結束後不會因仍在水下而無限續鎖，回到門檻內後才重新武裝。

## 可執行性

本策略未達月均 5%、未贏過 0050，且組合後報酬與回撤均劣於單獨營收事件策略，因此不可進紙上交易、不可實盤、不可接真實券商下單。下一輪應改驗證較強的純個股截面動能核心，不再微調本組合。

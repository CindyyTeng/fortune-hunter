# 個股現金流品質 Hunter v3 摘要

本輪延續 v2 的現金流品質方向，排除前一版在驗證期表現不穩的 `quality_momentum` 設定，並改用訓練期風險調整分數挑選參數。

## 結果

- 驗證月份：52 個月。
- 月均總資產報酬：-0.0754%。
- 年化報酬：-1.095%。
- 最大回撤：-14.8568%。
- 交易筆數：255 筆。
- Profit Factor：0.9277。
- 勝率：41.1765%。

## 結論

v3 比 v2 更差，未達月均 5% 目標，交易筆數也不足 300 筆。因此不可 paper trading、不可實盤、不可接券商 API。

本結果保留為失敗紀錄，避免後續重複測同一方向的小幅變體。

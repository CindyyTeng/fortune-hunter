# 殘差產業動能 v2

本輪測試目的：確認「個股相對大盤強、相對產業強」是否能形成可實盤的純個股策略。

## 回測結果

- 驗證期間：2020-09-01 到 2025-08-31
- 驗證月數：60 個月
- 交易筆數：517
- 月均總資產報酬：-0.4936%
- 年化報酬：-5.8322%
- Profit Factor：0.6412
- 最大回撤：-29.8827%
- 勝率：45.2611%
- 0050 同期月均：1.3603%
- 公平隨機中位數月均：-0.6993%

## 結論

v2 交易數足夠，但績效為負、最大回撤過大，且輸給 0050。此策略不可進入 paper trading，不可實盤，也不可接券商 API。

這次結果代表「只靠相對大盤或相對產業殘差動能」不是目前最有希望的 alpha 來源。下一步應改測不同核心邏輯，而不是繼續微調此策略。

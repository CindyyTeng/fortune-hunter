# 個股 Meta Selector v2

## 目的

本版只測純個股模型切換，不使用 ETF 或 0050 作為主要標的。0050 僅作為績效比較基準。

v1 的問題是交易數充足，但月均不足且最大回撤略高於 -20%。v2 因此提高訓練期低回撤要求，嘗試保留交易數並降低回撤。

## 驗證設定

- 驗證區間：2018-11 到 2026-04。
- 驗證月份：90 個月。
- 候選配置：32 組。
- 每折訓練期：54 個月。
- 每折驗證期：18 個月。
- 成交規則：沿用共用交易模擬器，含手續費、交易稅、滑價與 T+2。

## 結果

- Validation 月均總資產報酬：1.55%。
- 年化報酬：18.66%。
- 最大回撤：-21.01%。
- 負月份：31。
- 交易數：897。
- 0050 同期月均：1.96%。
- 是否通過月均 5%：否。
- 是否贏過 0050：否。

## 結論

v2 沒有達成目標。它降低了交易數，也沒有有效改善最大回撤，月均還低於 v1。

這代表目前固定 Top5 / meta selector 這條路線不該再單靠參數微調。下一步若要繼續往月均 5% 推進，應新增真正不同的 alpha，例如更細的主力籌碼、分點資料、公司行動資料或更可靠的產業題材資料。

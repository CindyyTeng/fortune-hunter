# 純個股標準化意外盈餘策略驗證

## 結論

本策略只交易一般上市、上櫃個股，ETF 與 0050 交易占比為 0%，0050 僅作績效比較。標準化意外盈餘（SUE）具有正期望與良好 Profit Factor，但交易頻率與資金部署率不足，月均報酬仍明顯輸給 0050，不能進入紙上交易或實盤。

## 資料與時間安全

- 從公開 FinMind 財報資料回填 2015Q1 至 2026Q1。
- 成功覆蓋 431 檔、45 季、19,043 筆季度 EPS；39 檔因免費 API 當日請求上限未取得。
- 缺少逐筆歷史公布時間，採法定申報期限收盤後、下一交易日才可使用。
- 19,043 筆皆通過保守 point-in-time 規則，但不宣稱 fully verified。

## 策略邏輯

- `SUE = [(EPS_t - EPS_t-4) - 過去 8 次季節性 EPS 變化平均] / 標準差`。
- 每次財報可用後，在全市場或產業內做 SUE 橫斷面排名。
- 測試前 10%、20%、30%、40%、50%，集中持有 Top 10、20、30、40。
- 進場測試公告可用日、正向價格反應、三日內突破確認，均為收盤確認後隔日開盤成交。
- 測試 10、20、40、60 個交易日持有，較長持有加入移動停利。
- 排除成交值不足、異常價格、近 20 日漲幅過大與跳空超過 4% 的標的。
- 單筆帳戶風險 0.5%、單檔上限 10%，使用真實手續費、交易稅、滑價、T+2、停損與投組熔斷。

## Walk-forward 驗證

- 每段訓練 54 個月、驗證 18 個月，驗證期不可調參數。
- 合併驗證期間：2020-09-01 至 2026-06-09，共 70 個月。
- SUE 觀察值：14,735 筆；可交易觀察日：99 日。
- 共測 384 組，最終四段驗證使用各自訓練期選出的固定參數。

## 已否決擴張

- 公告後第 20、40 個交易日重新進場的 PEAD 續航模式，四段訓練期全部選擇不使用，代表重複進場沒有增加穩定 alpha。
- 放寬到前 30%／40% 讓月均從 0.2769% 提高至 0.3198%、交易從 169 筆提高至 204 筆，但最大回撤由 -6.4572% 增至 -8.0903%。
- 再放寬到前 50% 與 Top 40 沒有被任何訓練區段選中，結果不再改善。

## 自動交易狀態

- 每筆候選可產生 setup、trigger、invalidation、出場計畫與 order intent。
- 未達 300 筆、未贏過 0050、未達月均 5%，因此 `paperTradingReady=false`、`liveTradingReady=false`。
- 下一輪不可再微調 SUE 分位；應補不同的 point-in-time alpha，或建立多個已證明正期望且低相關的個股策略投組，再用共用成交與投組模擬器驗證。

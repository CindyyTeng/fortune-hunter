# 個股 Meta-label v1 紙上交易

## 目的

這是研究候選策略的受限紙上交易入口，不是真實下單程式。它只產生 `BUY`、`SELL`、`HOLD`、`SKIP` 決策，並把可執行的交易意圖送到模擬券商。

## 執行步驟

1. 執行 `npm run data:refresh-paper` 更新 OHLCV 與市場資料。
2. 啟動即時報價服務：`npm run live`。
3. 另開終端機執行：`npm run paper:meta-label-v1`。

紙上交易狀態會寫入 `data/paper-meta-label-state.json`，這個檔案已列入 `.gitignore`，不會被提交。

資料更新失敗時不會覆蓋基準資料；應先處理錯誤，再重新執行紙上交易。個股快取使用既有回測股票池，報告仍須保留倖存者偏差警告。

## 安全閘門

- 研究報告未通過時，狀態為 `BLOCKED`。
- OHLCV 最新資料超過 3 天時，狀態為 `SKIP`，不使用歷史價格代替今日訊號。
- 即時報價服務失敗或沒有報價時，狀態為 `SKIP`。
- 所有委託只送至 `MockBrokerAdapter`，固定使用 `submitToRealBroker: false`。
- 模擬成本包含買賣手續費、賣出交易稅與滑價；這不是券商實際成交保證。

## 觀察門檻

至少累積 30 至 60 個交易日的紙上紀錄，再檢查成交率、滑價、停損執行、月度損益與資料缺失。即使紙上交易結果良好，也必須先補上券商 API 的身分驗證、委託回報、斷線重連、重複下單防護與人工解鎖，才可進入下一階段。

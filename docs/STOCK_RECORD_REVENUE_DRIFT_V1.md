# 純個股營收創高公告漂移 v1

## 結論

本次找到可重複觀察的正向事件效果，但完整 walk-forward 投組沒有達到可實盤門檻，也沒有達到月均 5%。不得進入紙上交易或實盤。

| --- | ---: |
| 驗證區間 | 2020-09-01 至 2026-06-09 |
| 每折訓練／驗證 | 54／18 個月 |
| 驗證月份 | 70 |
| 驗證交易 | 291 筆 |
| 月均總資產報酬 | 0.3498% |

策略優於同日同交易數的公平隨機，但仍輸給 0050，且距離月均 5% 尚差 4.6502 個百分點。

## 資料與時間邊界

- 月營收資料由 65 個月擴充到 137 個月，處理後為 54,233 筆、446 檔個股。
- 政府開放資料的現行 CSV 提供當期彙總；舊 MOPS 靜態歷史網址目前無法穩定回填，因此歷史值使用 FinMind 的公開月營收介面快取。
- 歷史資料沒有逐筆公告時間，故不是 fully verified point-in-time。
- 採保守規則：營收月份次月申報期限後才標記可用；策略再等有效日收盤確認，下一交易日才進場。
- 排名只使用訊號日以前資料；隔日跳空只在實際執行階段決定成交或放棄，不會用隔日資料替補排名。
- 回測使用共用成交與投組模擬器，包含手續費、交易稅、滑價、T+2、跳空停損較差成交價及風控熔斷。

官方資料欄位與授權可參考[政府資料開放平臺：上市公司每月營業收入彙總表](https://data.gov.tw/dataset/18420)。事件漂移假說參考 SSRN 的[月營收創高公告研究](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5345252)，但本專案以自己的 point-in-time walk-forward 結果為準，不把論文摘要當成策略有效證明。

## 事件研究

最佳單筆事件為「12 個月營收新高且 YoY 加速，持有 40 日」：1,618 筆、扣成本平均 5.6444%、中位數 0.3934%、勝率 51.5451%、PF 2.1203。

事件統計看似良好，但完整投組只有 17.6932% 平均曝險，且不同滾動驗證區間選到的持有期與條件不一致。這代表事件頻率與穩定性不足；直接放大部位只能同步放大回撤，不能視為有效改善。

## 下一步

1. 先完成剩餘月營收快取；HTTP 402 時安全停止，下次只續補缺口。
2. 補足可合法取得的實際公告時間、歷史下市股票池與公司行動，降低時間假設及倖存者偏差。
3. 優先尋找能提高交易頻率且與急跌止穩、營收漂移低相關的新資料 alpha，而不是微調這個失敗投組。
4. 在任何候選達到長期 validation 月均至少 5%、PF 大於 1.15、回撤小於 20%、交易至少 300 筆並勝過 0050 與公平隨機前，不可宣稱可實盤。

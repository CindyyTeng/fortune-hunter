# 自動交易落地狀態

## 目前結論

個股 Meta-label v1 在 2021-07 至 2026-06 的五段滾動驗證達到月均 8.4051%，並通過成本壓力測試；這只代表研究候選通過，不代表已可實盤。

- 紙上交易：可進入受限驗證，必須人工審核 order intent。
- 真實券商 API：尚未接線。
- 真實下單：禁止；程式固定輸出 `submitToRealBroker=false`。
- 資料風險：目前股票池存在倖存者偏差，報告標示 `survivorshipBiasWarning=true`。

## 開放條件

必須先完成至少 30～60 個交易日紙上交易，確認訊號、成交、滑價、停損、T+2、資金與交易日誌一致；之後仍需人工審核，不能直接解鎖真實下單。

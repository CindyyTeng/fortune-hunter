# 固定 Top5 純個股模型 v12 驗證摘要

## 目的

本輪只測純個股策略，0050 僅作為基準比較，不作為主要選股標的。v12 的核心變更是：不再只挑訓練期月均最高的參數，而是把訓練期拆成三段，要求分段穩定，降低「只靠單一行情」的風險。

## 驗證設定

- 訓練期：2016-08 到 2021-12。
- 分段訓練：2016-08 到 2018-05、2018-06 到 2020-03、2020-04 到 2021-12。
- 驗證期：2022-01 到 2026-05。
- 測試組合：1,536 組。
- 成交模型：沿用共用交易模擬器，包含手續費、交易稅、滑價、T+2 與既有風控。

## v12 結果

- Validation 月均總資產報酬：1.52%。
- 年化報酬：17.69%。
- 最大回撤：-18.15%。
- 交易筆數：388。
- Profit Factor：1.60。
- 勝率：36.86%。
- 是否贏過 0050：否。
- 是否達到月均 5%：否。

## 結論

v12 有改善回撤，且交易數仍高於 v7，但月均報酬沒有大幅提高，也沒有贏過 0050，因此不可 paper trading、不可實盤、不可接真實券商 API。

目前最接近高報酬的是 v7，但 v7 最大回撤太深且仍輸 0050；目前較平衡的是 v12，但月均仍離 5% 很遠。下一步若要繼續找個股策略，不應再只在固定 Top5 參數附近微調，應該改測新的核心 alpha，例如事件後續航、強勢股分批進出、或加入更可靠的基本面與籌碼品質資料。
